What is Linux? Kernel, distro, shell, GUI vs CLI

1. Objective

Installing VirtualBox and Linux OS on my laptop (RIP).

2. Commands & Links

No commands used. Installation and download links used:

  • VirtualBox: virtualbox.org
  • VirtualBox Dependencies (MS Visual C++ Redistributables): Microsoft Docs
  • LordOS Linux: lordos.org

3. Root Cause & Takeaway

My laptop could not handle Ubuntu Desktop 26.10 LTS due to heavy resource usage, so I switched to LordOS Linux, which runs smoothly inside VirtualBox.

Linux is a family of open-source Unix-like operating systems built on the Linux kernel (the core that manages hardware, memory, and processes). A distro (Ubuntu, Fedora, Debian) combines the kernel + package manager + utilities into a full OS. The shell (Bash, Zsh) is the command interpreter inside a terminal window. CLI is the text-based interface (universal and scriptable), while GUI is the graphical layer (GNOME, KDE) on top of X11/Wayland.
